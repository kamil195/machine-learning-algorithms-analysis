# Machine Learning Algorithms: Practical Implementation and Comparison

A notebook-based learning project that demonstrates a broad range of machine-learning and data-mining techniques using Python. The repository organizes the original coursework under a professional project title and preserves the implementation notebook and supporting presentation.

## Topics covered

- Linear and logistic regression
- K-nearest neighbors and support vector machines
- Neural-network demonstrations
- Principal component analysis
- Association-rule mining
- Bayesian-network concepts
- Genetic algorithms
- Semi-supervised learning experiments

## Repository structure

```text
notebooks/machine_learning_algorithms.ipynb
docs/machine_learning_project_presentation.pptx
requirements.txt
```

## Running the notebook

```bash
pip install -r requirements.txt
jupyter notebook notebooks/machine_learning_algorithms.ipynb
```

## Portfolio note

This is an educational comparison project rather than a single production model. Some sections use synthetic or demonstration datasets. Results should be interpreted as algorithm illustrations, not as a benchmark on one unified dataset.
